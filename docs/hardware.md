## 蜂鸣排查

Yahboom 官方控制板说明将蜂鸣器注明为低电压报警，MCU 指示灯低压时约每 100 ms 闪烁。USB 能给逻辑部分供电不代表电机电池电压正常。当前不能仅凭声音确定是电池、阈值、固件或线路问题，不关闭报警来掩盖原因。

排查顺序：被动查看日志和固件 → 检查电池标签及电压/极性 → 核对电池串数配置 → 断电检查线序 → 条件满足后外电供电验证。不要凭颜色猜电源正负，不要往 GPIO 或 USB 接口接电池电压。

## 后续按次序执行

1. 系统依赖与摄像头画面验证；ESP32 被动串口检查。
2. 查明现有固件的通信模式、协议及 ROS_DOMAIN_ID；若需更新固件，先保存原固件/配置。
3. 核对各电机端口到实际左前、右前、左后、右后的对应；白色插头在板端，黑色在电机端。
4. 核实电机看门狗可在通信中断时停止。轮子悬空下逐轮短脉冲测试，再测编码器方向。
5. S2 舵机从当前机械位置小幅测试；记录最低/最高安全角度、平台行程、带载离地净空和堵转风险。未标定前不发送 0/180 度或上一届默认角度。
6. 先实现低速遥控；同时保留人工能迅速切断电机电源的条件。
7. 用户同意接雷达后，仅通过配套转接板 DATA USB 连接；核对 MS200p 协议、角度方向和实际距离。
8. 测量车体/货架轮廓、雷达和摄像头相对底盘的位置与方向，再做地面导航。
9. 确认充电宝输出能力，验证摄像头/雷达/计算负载同时工作时树莓派不欠压；最后才改为比赛供电。

## 共用电池供电评估

厂家说明此 micro-ROS 控制板的专用 Type-C 电源输出支持树莓派5的5.1V/5A PD供电，因此规格上可以用同一电池供底盘和树莓派。接法为电池→控制板→专用供电Type-C口→树莓派USB-C；通信仍用另一条USB数据线。不能将7.4–8.4V电池直接接树莓派，不能把串口口或电池充电口当作树莓派电源输出。

当前尚未更换接线、未验证共用供电稳定性。先完成固件备份；随后正常关机、断电换线，验证相机、计算负载及电机/舵机工作时无欠压、USB掉线或重启。联合电机测试应在轮向和MCU失联保护解决后、悬空且有人看护时进行。低电量必须留出停车和正常关机余量，不能等电池保护板突然切电。50A放电额定值不能用于计算续航，电池容量仍需确认。

官方依据：[Yahboom控制板](https://github.com/YahboomTechnology/MicroROS-Board)、[树莓派5供电要求](https://www.raspberrypi.com/documentation/computers/getting-started.html#power-supply)。目前结论是“规格允许，实车待验”，不是已经验收可用。
